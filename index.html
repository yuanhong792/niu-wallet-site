当前功能What it does today

以下均为 v0.3.10 已实现并通过自动化回归测试的功能，不含路线图承诺。Everything below ships in v0.3.10 and passes automated regression tests. Nothing here is a roadmap promise.

钱包基本操作Core wallet

概览查看总余额、区块高度与节点连接状态；选择付款地址发送 NIU；接收页生成地址二维码；交易记录可展开完整链上字段。Overview shows balance, block height and node status. Send NIU from a chosen address, receive with a QR code, and expand full on-chain fields for any transaction.

ERC-20 代币ERC-20 tokens

一键发行固定总量或带上限的管理型 ERC-20，支持导入、查看余额和转账。交易列表自动解析 transfer / transferFrom 的真实数量与符号。Issue a fixed-supply or capped managed ERC-20 in one click, then import, check balances and transfer. The transaction list resolves real amounts and symbols from transfer / transferFrom.

Solidity 工作台Solidity studio

在钱包内编辑、编译 London EVM 合约、估算 Gas 并部署，支持导入 ABI 对已保存合约执行只读或签名写入调用。Edit, compile for London EVM, estimate Gas and deploy from inside the wallet. Import an ABI to run read calls or signed writes on saved contracts.

本机 PoW 挖矿Local PoW mining

在钱包中主动开启或停止 Ethash 挖矿，实时查看出块与算力状态。难度沿用 EIP-100 形状、42 秒时间桶并禁用难度炸弹。Start or stop Ethash mining from the wallet and watch blocks and hashrate. Difficulty follows the EIP-100 shape with a 42-second bucket and the difficulty bomb disabled.

备份与恢复Backup & restore

导出带独立密码的可携带 JSON 备份（ethers V3 keystore，scrypt + AES-128-CTR），导入时明确区分钱包口令与备份密码。项目方无法找回丢失的备份密码。Export a portable JSON backup with its own password (ethers V3 keystore, scrypt + AES-128-CTR). Import distinguishes the wallet passphrase from the backup password. Lost backup passwords cannot be recovered by anyone else.

简体中文、English、日本語、한국어、Español、Русский。macOS 与 Windows 共用同一实现与同一套文案。Simplified Chinese, English, Japanese, Korean, Spanish and Russian. macOS and Windows share one implementation and one string set.

这些数字意味着什么What these numbers mean

  • 整数舍入后的基础发行总额小于 21 亿 NIU，全部来自挖矿，没有创世预分配。Total base issuance after integer rounding is below 2.1 billion NIU, all from mining, with no genesis pre-allocation.
  • 目标平均出块约 60 秒，但这不是固定 60 秒的承诺：算力骤变、时间戳操纵、深度重组和长期运行仍需要更多独立验证。Average block time targets about 60 seconds, but that is not a fixed-60s guarantee. Hashrate shocks, timestamp manipulation, deep reorgs and long-run behaviour still need independent verification.
  • 钱包在本机运行节点并把链数据保存在用户目录，默认连接项目配置的共享节点，同步的是同一条网络历史。The wallet runs a local node and stores chain data in your user directory, connecting to project-configured peers by default so it syncs the same chain history.
  • 只有连接到相同 Chain ID、创世哈希与共识规则的节点，余额和已挖区块才会在不同电脑上得到一致结果。Balances and mined blocks only agree across machines when nodes share the same Chain ID, genesis hash and consensus rules.
  • 当前不是抗量子链。This is not a post-quantum chain.

安全状态Security status

先说结论The short version

当前版本未经独立第三方安全审计，不适合存放无法承受损失的资产。程序更新、系统故障、密码遗失、恶意软件和错误网络配置都可能造成资产无法使用。请保留多份离线备份，并先用小额测试恢复流程。This version has not been independently audited and is not suitable for assets you cannot afford to lose. App updates, system failures, lost passwords, malware and wrong network settings can all make funds unusable. Keep multiple offline backups and test recovery with a small amount first.

已完成的保护与验证Done

  • 钱包请求校验 Host、Origin 和随机会话令牌；限制 JSON 类型、请求体大小、连接与读取时间；错误信息不回显请求中的秘密。Wallet requests validate Host, Origin and a random session token; JSON types, body size, connection and read times are limited; errors never echo secrets from the request.
  • RPC、矿工控制与钱包控制接口保持在本机回环地址；P2P 只按明确的网络配置连接节点。RPC, miner and wallet control interfaces stay on the loopback address; P2P connects only to explicitly configured peers.
  • 签名类操作需要先解锁钱包，空闲约 5 分钟自动上锁，也可手动立即上锁。Signing operations require unlocking; the wallet auto-locks after about 5 minutes idle and can lock immediately.
  • 可携带备份使用 ethers V3 keystore，导出后立即解密回读校验；导入前限制文件大小与 KDF 参数，拒绝错误密码、篡改密文、错误网络参数和危险覆盖。Portable backups use an ethers V3 keystore and are decrypted and re-read right after export. Import limits file size and KDF parameters, and rejects wrong passwords, tampered ciphertext, wrong network parameters and dangerous overwrites.
  • 恢复测试在隔离数据目录中完成，不会覆盖正在使用的钱包。Recovery tests run in an isolated data directory and never overwrite a live wallet.
  • Solidity 编译器只允许读取固定安装的 OpenZeppelin 依赖，拒绝任意本机文件导入，并限制源码、参数、部署字节码和 EVM 运行时代码大小。The Solidity compiler may only read the pinned OpenZeppelin dependency, rejects arbitrary local file imports, and caps source, arguments, deployed bytecode and runtime code size.
  • ERC-20 显示同时校验标准 calldata 与已确认的 Transfer 日志；链上名称、符号和精度属于合约自报元数据，无法验证时在界面明确标记，不伪装成已验证代币。ERC-20 display checks both standard calldata and confirmed Transfer logs. On-chain name, symbol and decimals are contract-supplied metadata, marked explicitly when unverifiable rather than presented as verified.
  • v0.3.10 通过 25 项钱包回归测试与六语言静态覆盖检查，并保留真实双节点链上的 ERC-20 发行/转账与合约部署/读写验证。v0.3.10 passes 25 wallet regression tests and a six-language static coverage check, keeping real two-node ERC-20 issuance/transfer and contract deploy/read-write verification.

尚未完成Not done

  • 未完成独立第三方安全审计。No independent third-party security audit.
  • 未完成 Apple Developer ID 签名与公证，Windows 包未做商业代码签名。No Apple Developer ID signing or notarization; the Windows build is not commercially code-signed.
  • 未完成更多实体电脑、不同网络环境下的长期同步与故障恢复验证。Long-run sync and failure recovery across more physical machines and networks is unverified.
  • 未完成深度链重组、节点隔离、长期难度变化和异常时间戳的充分模拟。Deep reorgs, node isolation, long-term difficulty drift and abnormal timestamps are not adequately simulated.
  • 未建立私密漏洞接收渠道或漏洞赏金计划。No private vulnerability disclosure channel or bug bounty.
  • Solidity 编辑器与内置合约模板未经独立智能合约安全审计。DEX、跨链桥、WalletConnect、ENS 与 NFT 图形化管理不在 v0.3.10 范围内。The Solidity editor and bundled contract templates are not independently audited. DEX, bridges, WalletConnect, ENS and NFT asset management are out of scope for v0.3.10.
  • 构建依赖仍有 1 条 sprintf-js 中危记录，当前依赖链没有可直接升级的已修复版本。Build dependencies still carry one medium sprintf-js advisory with no directly upgradable fixed version in the current dependency chain.

本机保护的真实边界What local protection does not cover

Windows 本机钱包文件由 DPAPI CurrentUser 保护；macOS 使用 AES-256-GCM，主密钥保存在当前用户钥匙串。钱包口令是应用内门禁，不能抵御已经完全控制该系统账户、钥匙串或进程的攻击者。离开电脑时仍应锁定系统并保持操作系统更新。On Windows the local wallet file is protected by DPAPI CurrentUser; on macOS it uses AES-256-GCM with the key held in the current user's Keychain. The wallet passphrase is an in-app gate — it does not defend an attacker who already controls the OS account, Keychain or process. Lock your machine when you step away and keep the OS updated.

扫描结果只能证明已知规则下未发现对应问题，不能证明不存在未知漏洞。源码公开、自动化测试和依赖扫描均不构成第三方安全背书。完整说明见仓库 SECURITY.md。Scan results only prove that no matching issue was found under known rules; they cannot prove unknown vulnerabilities are absent. Public source, automated tests and dependency scans are not third-party assurance. Full statement in the repo's SECURITY.md.
